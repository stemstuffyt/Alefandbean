# Bean & Alef — Coffee Shop Page

This is a simple static HTML/CSS landing page for a coffee shop.

Open [index.html](index.html) in your browser to view the page:

```bash
open index.html
```

Files included:

- [index.html](index.html) — main HTML file
- [styles.css](styles.css) — styles for the page

This is a demo static page; the contact form is non-functional and shows an alert when submitted.
